# 布隆过滤器对比工具

标准布隆过滤器 vs 计数布隆过滤器的可视化对比工具。

**技术栈**：Web Worker（计算隔离，主线程不卡）+ TypedArray（`Uint8Array` 位图/计数器）+ Canvas（填充率可视化）+ Web Crypto（SHA-256 派生哈希种子）。

## 运行

浏览器安全策略禁止 `file://` 加载 Worker，需本地起服务：

```bash
cd 本目录
python3 -m http.server 8000   # 或 npx serve
# 打开 http://localhost:8000
```

## 功能

- **可配置参数**：位数组大小 m、哈希函数个数 k（1–64）、操作数量 n；实时提示最优 k 与理论误判率
- **操作**：插入、查询（测误判率）、删除（仅计数布隆，删除前校验成员存在防止误减）、重置
- **量化对比**：内存占用、填充率、理论/实测误判率、插入/查询/删除吞吐、计数溢出次数
- **可视化**：Canvas 色带展示位数组密度分布（蓝→红 = 空→满）+ 填充率进度条，插入过程实时刷新

## 关键设计

- **哈希函数**：MurmurHash3 (x86_32) 双哈希 `pos_i = (h1 + i·h2) mod m`，h2 强制为奇数保证遍历整个位数组；种子由 Web Crypto SHA-256 派生
- **边界**：位置恒在 `[0, m)`，位图按 `ceil(m/8)` 字节分配，m 无需是 8 的倍数
- **计数溢出**：计数器饱和在 255 不回绕，溢出次数单独统计；饱和计数删除时保守不递减
- **理论误判率**：`p = (1 - e^(-kn/m))^k`，与实测值同屏对比
- **大数据量**：批量操作分块（5 万/块）执行，块间让出事件循环，百万级插入主线程零阻塞
